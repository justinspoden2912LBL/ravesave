# Rave Safe

Baue eine App, welche für den Konsumenten von Substanzen dazu eignet, Protokoll zu führen, über die eingenommen Substanzen inklusive dazu ein MISCHKONSUM Risiko Einschätzung Parameter nehme als Grunds Substanzen alle klassischen Drogen zusätzlich cathinone und Pyrocathinone



Aber auch Neuroleptika, Opioide und andere Medikamente zu jeder Substanz sollte entweder durchklinische Studien oder evidenzbasierte Fakten, Informationen einsehbar sein sowie eine grobe Dosierung Vorgabe
